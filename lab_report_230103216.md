- At p=6: stride=1 median 1430.78 ms vs stride=16 median 1360.15 ms (ratio 1.05x).

### Forensic explanation
Cache coherence protocols (MESI/MOESI) track ownership per cache line (64 B on x86-64, 128 B on Apple M-series),
not per word. When several cores write different 8-byte words that live on the same line, every store invalidates
the line in the other cores' caches, so the line ping-pongs between cores although no datum is logically shared:
this is **false sharing**. Stride 8 (8 x 8 B = 64 B) is the first separation that puts neighbouring slots on
different 64-byte lines; stride 16 (128 B) isolates slots on 128-byte-line CPUs and is also safe on 64-byte CPUs
because adjacent-line prefetchers often pair lines. With stride = 1 all workers hit one line, so the useful
(parallel) fraction shrinks and the Karp-Flatt serial fraction e(p) grows with p, because coherence stalls act as
extra serial work that does not shrink with more workers. With stride = 16, e(p) stays low and roughly constant if
the loop scales. Compare the e(p) trajectories in Table 1B above; if they do not differ clearly, the dominant cost
on this machine is the Python interpreter loop (hundreds of ns per iteration) rather than coherence traffic, and
that limitation should be stated rather than hidden.

### Interpretation
*Strong scaling* fixes the problem size and asks how much faster p workers finish; Amdahl's law bounds it by the
serial fraction: S(p) = 1 / (s + (1-s)/p), S_inf = 1/s. *Weak scaling* grows the problem with p and asks whether the
time stays constant; Gustafson's scaled speedup is S(p) = p - alpha (p-1), where alpha is the serial share of the
parallel run. Here the serial Stage A covers 5% of N(p), so it grows with p in the weak experiment, which is why
E_weak falls below 1 and alpha is reported per p. Up to P_phys each worker has a private core; beyond it
(Hyper-Threading/SMT or efficiency cores) workers share execution units, so the marginal speedup per added worker
drops - quantified above. Differences between measured and theoretical Amdahl speedup come from pool dispatch cost,
memory/turbo/thermal effects and the SMT sharing, none of which Amdahl's model contains.

### Interpretation
K(i) grows quadratically, so contiguous static blocks give the last worker most of the work (lambda well above
1.00, other workers idle at the join barrier). Cyclic assignment interleaves cheap and expensive items and
balances almost perfectly for this smooth skew. The dynamic queue balances at run time: with C = 1 the tail skew is
minimal but every item takes the shared counter's lock (cache-line ping-pong and lock hand-off cost); with large C
(e.g. 1024) synchronisation is negligible but the last claimed chunks - which contain the most expensive items -
can leave one worker running long after the rest finish (high lambda, idle time). The best chunk C\* balances both
effects; because each item here costs thousands of trigonometric iterations, lock overhead is small relative to
the work, so a smaller C is often competitive - compare the measured table above.

```python
@dataclass
class BenchStats:
    """Summary of timed runs, all values in milliseconds."""
    min_ms: float
    median_ms: float
    iqr_ms: float
    max_ms: float

    def to_dict(self) -> Dict[str, float]:
        return asdict(self)


def fnv1a_hash(s: str) -> int:
    """64-bit FNV-1a hash of a UTF-8 string (exactly as in the assignment)."""
    h = FNV_OFFSET_BASIS
    for b in s.encode("utf-8"):
        h ^= b
        h = (h * FNV_PRIME) & MASK64
    return h


def bench_stats_from_samples(samples_ms: Sequence[float]) -> BenchStats:
    """min / median / IQR / max with the same indexing as the assignment's harness."""
    if len(samples_ms) == 0:
        raise ValueError("no samples")
    s = sorted(samples_ms)
    n = len(s)
    mid = n // 2
    med = s[mid] if n % 2 == 1 else 0.5 * (s[mid - 1] + s[mid])
    q25 = s[n // 4]
    q75 = s[(3 * n) // 4]
    return BenchStats(s[0], med, q75 - q25, s[-1])


def median(values: Sequence[float]) -> float:
    """Median of a non-empty sequence."""
    return bench_stats_from_samples(values).median_ms


def run_benchmark(fn: Callable[[], None], warmup_runs: int = 3, timed_runs: int = 9) -> BenchStats:
    """Run fn() `warmup_runs` times untimed, then `timed_runs` times timed
    (time.perf_counter_ns). Returns wall-clock statistics in ms."""
    if warmup_runs < 0:
        raise ValueError("warmup_runs must be >= 0")
    if timed_runs < 1:
        raise ValueError("timed_runs must be >= 1")
    for _ in range(warmup_runs):
        fn()
    samples: List[float] = []
    for _ in range(timed_runs):
        t0 = time.perf_counter_ns()
        fn()
        t1 = time.perf_counter_ns()
        samples.append((t1 - t0) / 1e6)
    return bench_stats_from_samples(samples)

def balanced_ranges(n: int, parts: int) -> List[Tuple[int, int]]:
    """Split range(n) into `parts` contiguous, nearly equal [start, end) ranges."""
    base, rem = divmod(n, parts)
    out, start = [], 0
    for t in range(parts):
        end = start + base + (1 if t < rem else 0)
        out.append((start, end))
        start = end
    return out

@contextmanager
def managed_shared_memory(size: int) -> Iterator[shared_memory.SharedMemory]:
    """Create a SharedMemory block and guarantee close()+unlink() on exit.

    Callers must release any ctypes/memoryview exports of shm.buf before leaving
    the with-block, otherwise close() raises BufferError (reported, not fatal).
    """
    if size <= 0:
        raise ValueError("size must be positive")
    shm = shared_memory.SharedMemory(create=True, size=size)
    try:
        yield shm
    finally:
        try:
            shm.close()
        except BufferError:
            print("[warn] shared memory still has exported buffers; close skipped",
                  file=sys.stderr)
        try:
            shm.unlink()
        except FileNotFoundError:
            pass


_SYNC_BARRIER: Any = None


def _sync_pool_init(barrier: Any, user_init: Optional[Callable[..., None]],
                    user_args: Tuple[Any, ...]) -> None:
    """Pool initializer: stash the barrier, then run the caller's own initializer."""
    global _SYNC_BARRIER
    _SYNC_BARRIER = barrier
    if user_init is not None:
        user_init(*user_args)


def sync_point(timeout: float = 300.0) -> None:
    """Call at the start of a pool task. Blocks until all `processes` workers arrived.

    Because a worker blocked here cannot pick up another task, this guarantees that a
    pool.map(..., chunksize=1) over exactly `processes` tasks runs one task per DISTINCT
    worker, all starting together.
    """
    if _SYNC_BARRIER is None:
        raise RuntimeError("sync_point() used outside a pool made by create_synced_pool()")
    _SYNC_BARRIER.wait(timeout)


def create_synced_pool(processes: int, user_init: Optional[Callable[..., None]] = None,
                       user_args: Tuple[Any, ...] = ()) -> Any:
    """Persistent multiprocessing.Pool whose workers share a start barrier."""
    if processes < 1:
        raise ValueError("processes must be >= 1")
    barrier = mp.Barrier(processes)
    return mp.Pool(processes=processes, initializer=_sync_pool_init,
                   initargs=(barrier, user_init, user_args))


def deterministic_doubles(count: int, seed: int = 12345) -> "array[float]":
    """Reproducible pseudo-random doubles in [0,1) via a 64-bit LCG."""
    if count < 0:
        raise ValueError("count must be >= 0")
    state = seed & MASK64
    out = array("d", bytes(8 * count))
    for i in range(count):
        state = (state * 6364136223846793005 + 1442695040888963407) & MASK64
        out[i] = (state >> 11) / float(1 << 53)
    return out


def render_table(headers: Sequence[str], rows: Sequence[Sequence[Any]]) -> str:
    """Plain-text table for console output."""
    cells = [[str(c) for c in r] for r in rows]
    widths = [max([len(str(h))] + [len(r[i]) for r in cells]) for i, h in enumerate(headers)]
    line = "+" + "+".join("-" * (w + 2) for w in widths) + "+"
    fmt = "| " + " | ".join("{:<%d}" % w for w in widths) + " |"
    out = [line, fmt.format(*headers), line]
    out += [fmt.format(*r) for r in cells]
    out.append(line)
    return "\n".join(out)
```

```python
def parse_size_kb(text: Optional[str]) -> Optional[float]:
    """Parse '32K', '1280K', '48 KiB', '12 MiB' into KB (float)."""
    if not text:
        return None
    m = re.fullmatch(r"\s*(\d+(?:\.\d+)?)\s*([KMG])(?:i?B)?\s*", text, re.I)
    if not m:
        return None
    mult = {"K": 1, "M": 1024, "G": 1024 * 1024}[m.group(2).upper()]
    return float(m.group(1)) * mult

# Windows: PowerShell/WMI (as in the handout) + kernel32 for per-core caches
# ==========================================================================
class _CacheDesc(ctypes.Structure):
    _fields_ = [("Level", ctypes.c_ubyte), ("Associativity", ctypes.c_ubyte),
                ("LineSize", ctypes.c_ushort), ("Size", ctypes.c_uint32),
                ("Type", ctypes.c_uint32)]


class _SlpiUnion(ctypes.Union):
    _fields_ = [("Cache", _CacheDesc), ("Reserved", ctypes.c_ulonglong * 2)]


class _Slpi(ctypes.Structure):
    """SYSTEM_LOGICAL_PROCESSOR_INFORMATION"""
    _fields_ = [("ProcessorMask", ctypes.c_size_t), ("Relationship", ctypes.c_uint32),
                ("u", _SlpiUnion)]


def windows_topology_via_api() -> Optional[Dict[str, Any]]:
    """GetLogicalProcessorInformation: per-instance cache sizes, line size, core count."""
    try:
        kernel32 = ctypes.WinDLL("kernel32", use_last_error=True)  # type: ignore[attr-defined]
        length = ctypes.c_ulong(0)
        kernel32.GetLogicalProcessorInformation(None, ctypes.byref(length))
        if length.value == 0:
            return None
        count = length.value // ctypes.sizeof(_Slpi)
        buf = (_Slpi * count)()
        if not kernel32.GetLogicalProcessorInformation(buf, ctypes.byref(length)):
            return None
    except (OSError, AttributeError):
        return None
    cores, logical = 0, 0
    l1d: List[float] = []
    l2: List[float] = []
    l3: List[float] = []
    lines: List[int] = []
    for entry in buf:
        if entry.Relationship == 0:                       # RelationProcessorCore
            cores += 1
            logical += bin(entry.ProcessorMask).count("1")
        elif entry.Relationship == 2:                     # RelationCache
            c = entry.u.Cache
            kb = c.Size / 1024.0
            if c.Level == 1 and c.Type == 2:              # L1 data
                l1d.append(kb)
                lines.append(c.LineSize)
            elif c.Level == 2 and c.Type in (0, 2):       # L2 unified/data
                l2.append(kb)
            elif c.Level == 3 and c.Type in (0, 2):       # L3 unified/data
                l3.append(kb)
    return {"cores": cores, "logical": logical, "l1d": l1d, "l2": l2, "l3": l3, "lines": lines}


def detect_windows(hw: Dict[str, Any]) -> None:
    """Windows detection: PowerShell Win32_Processor + kernel32 + registry fallback."""
    ps = ("Get-CimInstance Win32_Processor | Select-Object Name,NumberOfCores,"
          "NumberOfLogicalProcessors,L2CacheSize,L3CacheSize | ConvertTo-Json -Compress")
    out = run_command(["powershell", "-NoProfile", "-NonInteractive", "-Command", ps], timeout=40)
    wmi_l2_total = wmi_l3_total = None
    if out:
        try:
            parsed = json.loads(out)
            procs = parsed if isinstance(parsed, list) else [parsed]
            hw["cpu_model"] = str(procs[0].get("Name", "")).strip() or None
            hw["physical_cores"] = sum(int(p.get("NumberOfCores") or 0) for p in procs) or None
            hw["logical_threads"] = sum(int(p.get("NumberOfLogicalProcessors") or 0) for p in procs) or None
            wmi_l2_total = procs[0].get("L2CacheSize")
            wmi_l3_total = procs[0].get("L3CacheSize")
            hw["sources"].update(cpu_model="PowerShell Win32_Processor",
                                 physical_cores="PowerShell Win32_Processor",
                                 logical_threads="PowerShell Win32_Processor")
        except (ValueError, TypeError, AttributeError):
            hw["notes"].append("PowerShell output could not be parsed")
    else:
        hw["notes"].append("PowerShell/WMI query failed")

    api = windows_topology_via_api()
    if api:
        if hw["physical_cores"] is None and api["cores"]:
            hw["physical_cores"] = api["cores"]
            hw["sources"]["physical_cores"] = "kernel32 GetLogicalProcessorInformation"
        if hw["logical_threads"] is None and api["logical"]:
            hw["logical_threads"] = api["logical"]
            hw["sources"]["logical_threads"] = "kernel32"
        hw["l1d_kb"] = pick_cache(api["l1d"], "L1d", hw)
        hw["l2_kb"] = pick_cache(api["l2"], "L2 (per instance)", hw)
        l3 = pick_cache(api["l3"], "L3", hw)
        hw["l3_mb"] = (l3 / 1024.0) if l3 else None
        if api["lines"]:
            hw["cache_line_bytes"] = max(api["lines"])
        for k in ("l1d_kb", "l2_kb", "l3_mb", "cache_line_bytes"):
            if hw[k] is not None:
                hw["sources"][k] = "kernel32 GetLogicalProcessorInformation"
    if hw["l2_kb"] is None and wmi_l2_total:
        hw["l2_kb"] = float(wmi_l2_total)
        hw["sources"]["l2_kb"] = "WMI (may be PACKAGE TOTAL)"
    if hw["l3_mb"] is None and wmi_l3_total:
        hw["l3_mb"] = float(wmi_l3_total) / 1024.0
        hw["sources"]["l3_mb"] = "WMI"
    if wmi_l2_total:
        hw["notes"].append(f"WMI L2CacheSize (often package total across cores) = {wmi_l2_total} KB")
    if hw["cpu_model"] is None:
        try:
            import winreg  # stdlib, Windows only
            with winreg.OpenKey(winreg.HKEY_LOCAL_MACHINE,
                                r"HARDWARE\DESCRIPTION\System\CentralProcessor\0") as k:
                hw["cpu_model"] = winreg.QueryValueEx(k, "ProcessorNameString")[0].strip()
                hw["sources"]["cpu_model"] = "registry"
        except Exception:
            pass

def detect_linux(hw: Dict[str, Any]) -> None:
    """Linux detection: /proc/cpuinfo, lscpu, sysfs cache directory, getconf."""
    cpuinfo = read_text("/proc/cpuinfo") or ""
    for key in ("model name", "Model", "Hardware", "Processor"):
        m = re.search(rf"^{key}\s*:\s*(.+)$", cpuinfo, re.M)
        if m:
            hw["cpu_model"] = m.group(1).strip()
            hw["sources"]["cpu_model"] = f"/proc/cpuinfo ({key})"
            break
    lscpu_all = run_command(["lscpu"])
    if hw["cpu_model"] is None and lscpu_all:
        m = re.search(r"^Model name:\s*(.+)$", lscpu_all, re.M)
        if m:
            hw["cpu_model"] = m.group(1).strip()
            hw["sources"]["cpu_model"] = "lscpu"

    hw["logical_threads"] = os.cpu_count()
    hw["sources"]["logical_threads"] = "os.cpu_count()"

    # Physical cores: lscpu -p -> /proc/cpuinfo ids -> sysfs sibling lists
    out = run_command(["lscpu", "-p=CORE,SOCKET"])
    if out:
        pairs = {tuple(l.split(",")[:2]) for l in out.splitlines() if l and not l.startswith("#")}
        if pairs:
            hw["physical_cores"] = len(pairs)
            hw["sources"]["physical_cores"] = "lscpu -p=CORE,SOCKET"
    if hw["physical_cores"] is None:
        phys = re.findall(r"^physical id\s*:\s*(\d+)", cpuinfo, re.M)
        core = re.findall(r"^core id\s*:\s*(\d+)", cpuinfo, re.M)
        if phys and len(phys) == len(core):
            hw["physical_cores"] = len(set(zip(phys, core)))
            hw["sources"]["physical_cores"] = "/proc/cpuinfo ids"
    if hw["physical_cores"] is None:
        sib = {read_text(p) for p in glob.glob("/sys/devices/system/cpu/cpu[0-9]*/topology/thread_siblings_list")}
        sib.discard(None)
        if sib:
            hw["physical_cores"] = len(sib)
            hw["sources"]["physical_cores"] = "sysfs thread_siblings_list"

    # Caches from sysfs (cpu0)
    for idx in sorted(glob.glob("/sys/devices/system/cpu/cpu0/cache/index*")):
        level = read_text(f"{idx}/level")
        ctype = read_text(f"{idx}/type")
        size = parse_size_kb(read_text(f"{idx}/size"))
        line = read_text(f"{idx}/coherency_line_size")
        if level == "1" and ctype == "Data":
            hw["l1d_kb"] = size
            hw["sources"]["l1d_kb"] = "sysfs cpu0"
            if line and line.isdigit():
                hw["cache_line_bytes"] = int(line)
                hw["sources"]["cache_line_bytes"] = "sysfs cpu0"
        elif level == "2" and ctype in ("Unified", "Data"):
            hw["l2_kb"] = size
            hw["sources"]["l2_kb"] = "sysfs cpu0"
        elif level == "3" and ctype in ("Unified", "Data") and size:
            hw["l3_mb"] = size / 1024.0
            hw["sources"]["l3_mb"] = "sysfs cpu0"

    # lscpu fallback (reports totals; divide L1d/L2 by instance count)
    if lscpu_all:
        for key, field in (("L1d", "l1d_kb"), ("L2", "l2_kb"), ("L3", "l3_mb")):
            if hw[field] is not None:
                continue
            m = re.search(rf"^{key} cache:\s*([\d.]+\s*[KMG]i?B?)(?:\s*\((\d+) instance)?", lscpu_all, re.M)
            kb = parse_size_kb(m.group(1)) if m else None
            if kb is None:
                continue
            if key != "L3" and m and m.group(2):
                kb /= int(m.group(2))
            hw[field] = kb / 1024.0 if key == "L3" else kb
            hw["sources"][field] = "lscpu"
    if hw["cache_line_bytes"] is None:
        out = run_command(["getconf", "LEVEL1_DCACHE_LINESIZE"])
        if out and out.isdigit() and int(out) > 0:
            hw["cache_line_bytes"] = int(out)
            hw["sources"]["cache_line_bytes"] = "getconf"

def _clock_read_loop(n: int) -> None:
    clock = time.perf_counter_ns
    for _ in range(n):
        clock()


def _empty_loop(n: int) -> None:
    for _ in range(n):
        pass


def measure_timer_resolution(samples: int) -> Dict[str, Any]:
    """Timer noise floor from back-to-back clock reads."""
    clock = time.perf_counter_ns
    prev = clock()
    deltas: List[int] = []
    for _ in range(samples):
        cur = clock()
        deltas.append(cur - prev)
        prev = cur
    positive = [d for d in deltas if d > 0]
    return {
        "samples": samples,
        "min_positive_delta_ns": min(positive) if positive else None,
        "median_delta_ns": sorted(deltas)[len(deltas) // 2],
        "zero_delta_fraction": 1.0 - len(positive) / len(deltas),
    }
```

### task1_falsesharing.py

```python
"""
task1_falsesharing.py - Phase 1: false sharing & cache-line contention.

Usage (PowerShell, inside parallel_lab/):
    python task1_falsesharing.py            # official parameters (asks for confirmation)
    python task1_falsesharing.py --yes      # no confirmation prompt
    python task1_falsesharing.py --quick    # reduced debug run (hash NOT valid)
    python task1_falsesharing.py --force    # re-run although results/phase1.json exists

Workload: M = 24,000,000 total read-modify-write steps split over p worker processes
(M // p each), every worker updating its own 64-bit slot `t * stride` in ONE 4096-byte
SharedMemory block through ctypes.c_uint64.

Measurement note (documented deviation / refinement of the handout):
  Workers attach, then wait on a barrier, then time ONLY their loop with perf_counter_ns().
  The primary time of a trial is max(worker loop times) ("kernel time"), which excludes
  process start-up (50-300 ms per process on Windows 'spawn' - larger than the signal we
  want to see). The wall time including spawn/join is recorded too (`wall_*`).
  Tables use kernel time; harness.run_benchmark(warmup_runs=2, timed_runs=7) drives the trials.

Estimated runtime (full): roughly 3-10 minutes; memory: ~30-40 MB per worker process.
VERIFY_HASH[PHASE1]: metric1 = median kernel ms (stride=1, p=P_phys),
                     metric2 = median kernel ms (stride=16, p=P_phys).
"""
from __future__ import annotations

import ctypes
import multiprocessing as mp
import struct
import sys
import time
from multiprocessing import shared_memory
from typing import Any, Dict, List, Optional, Tuple

import harness

SHM_BYTES = 4096                      # required buffer size
SLOTS = SHM_BYTES // 8                # 512 x uint64
STRIDES = [1, 2, 4, 8, 16, 32]        # 8 .. 256 bytes between slots
MASK = 0xFFFFFFFFFFFFFFFF
MULT = 6364136223846793005
BARRIER_TIMEOUT = 120.0


# ==========================================================================
# Worker (module level => picklable under Windows 'spawn')
# ==========================================================================
def fs_worker(shm_name: str, slot_idx: int, iters: int,
              barrier: Any = None, times: Any = None, worker_id: int = 0) -> None:
    """Deterministic LCG accumulation, one store to shared slot per iteration.

    barrier/times are optional: if given, the loop start is synchronised and its
    duration (ns) is stored in times[worker_id].
    """
    shm = shared_memory.SharedMemory(name=shm_name)
    arr = None
    try:
        arr = (ctypes.c_uint64 * SLOTS).from_buffer(shm.buf)
        acc = arr[slot_idx]
        mask = MASK
        mult = MULT
        if barrier is not None:
            barrier.wait(BARRIER_TIMEOUT)
        t0 = time.perf_counter_ns()
        for i in range(iters):
            acc = (acc * mult + (i | 1)) & mask
            arr[slot_idx] = acc            # direct store to the (possibly shared) cache line
        t1 = time.perf_counter_ns()
        if times is not None:
            times[worker_id] = t1 - t0
    except BaseException:
        if barrier is not None:
            try:
                barrier.abort()
            except Exception:
                pass
        raise
    finally:
        arr = None                         # drop ctypes export before closing the mapping
        try:
            shm.close()
        except BufferError:
            pass


# ==========================================================================
# One trial / one configuration
# ==========================================================================
def run_once(shm: shared_memory.SharedMemory, p: int, stride: int,
             iters: int) -> Tuple[float, float, bool]:
    """Run p workers once. Returns (kernel_ms, wall_ms, values_consistent)."""
    shm.buf[:SHM_BYTES] = bytes(SHM_BYTES)                 # reset all slots to 0
    barrier = mp.Barrier(p)
    times = mp.RawArray("q", p)
    procs = [mp.Process(target=fs_worker,
                        args=(shm.name, t * stride, iters, barrier, times, t))
             for t in range(p)]
    t0 = time.perf_counter_ns()
    for pr in procs:
        pr.start()
    for pr in procs:
        pr.join()
    wall_ms = (time.perf_counter_ns() - t0) / 1e6
    bad = [pr.exitcode for pr in procs if pr.exitcode != 0]
    if bad:
        raise RuntimeError(f"worker failure, exit codes: {bad}")
    kernel_ms = max(times[:]) / 1e6
    values = [struct.unpack_from("<Q", shm.buf, t * stride * 8)[0] for t in range(p)]
    consistent = len(set(values)) == 1                     # identical recurrence in every worker
    return kernel_ms, wall_ms, consistent


def measure(shm: shared_memory.SharedMemory, p: int, stride: int, total_iters: int,
            warmup: int, timed: int) -> Dict[str, Any]:
    """Benchmark one (p, stride) configuration."""
    iters = total_iters // p
    kernel: List[float] = []
    consistent_flags: List[bool] = []

    def trial() -> None:
        k_ms, _w, ok = run_once(shm, p, stride, iters)
        kernel.append(k_ms)
        consistent_flags.append(ok)

    wall_stats = harness.run_benchmark(trial, warmup_runs=warmup, timed_runs=timed)
    k_stats = harness.bench_stats_from_samples(kernel[warmup:])
    total_ops = iters * p
    return {
        "p": p, "stride": stride, "byte_separation": stride * 8,
        "iters_per_worker": iters, "total_ops": total_ops,
        "median_ms": k_stats.median_ms, "iqr_ms": k_stats.iqr_ms,
        "min_ms": k_stats.min_ms, "max_ms": k_stats.max_ms,
        "throughput_mops": total_ops / (k_stats.median_ms * 1e3),
        "wall_median_ms": wall_stats.median_ms,
        "values_consistent": all(consistent_flags),
    }


def karp_flatt(speedup: float, p: int) -> Optional[float]:
    """Experimentally determined serial fraction e(p) = (1/S - 1/p) / (1 - 1/p), p >= 2."""
    if p < 2:
        return None
    return (1.0 / speedup - 1.0 / p) / (1.0 - 1.0 / p)


def fits(stride: int, p: int) -> bool:
    """True if the slots 0, stride, ..., (p-1)*stride fit into the 512-slot buffer."""
    return stride * (p - 1) < SLOTS


def process_counts(p_phys: int, p_log: int) -> List[int]:
    """1, 2, 4, ... <= P_log, plus P_phys and P_log themselves (needed for the hash / ceiling)."""
    counts = set()
    p = 1
    while p <= p_log:
        counts.add(p)
        p *= 2
    counts.update({p_phys, p_log})
    return sorted(counts)


# ==========================================================================
# Estimation
# ==========================================================================
def calibrate_ns_per_iter(n: int = 400_000) -> float:
    """Single-process cost of the worker loop (local list instead of shared memory)."""
    buf = [0] * 8
    acc = 0
    t0 = time.perf_counter_ns()
    for i in range(n):
        acc = (acc * MULT + (i | 1)) & MASK
        buf[0] = acc
    return (time.perf_counter_ns() - t0) / n


def estimate(m: int, counts: List[int], p_phys: int, warmup: int, timed: int) -> str:
    """Rough runtime / memory estimate for the whole phase."""
    ns = calibrate_ns_per_iter()
    runs = warmup + timed
    spawn_s = 0.15
    total = sum(m / p * ns / 1e9 + spawn_s * p for p in counts) * runs * 2           # two scaling sweeps
    total += sum(m / p_phys * ns / 1e9 + spawn_s * p_phys for _ in STRIDES) * runs   # stride sweep
    return (f"[estimate] loop cost ~{ns:.0f} ns/iter -> p=1 trial ~{m * ns / 1e9:.1f} s; "
            f"whole phase ~{total / 60:.1f} min (uncontended lower bound; false sharing makes it slower).\n"
            f"[estimate] memory: 4 KB shared + ~{max(counts) * 35} MB for the largest worker set.")


# ==========================================================================
# Analysis helpers
# ==========================================================================
def find_inflection(rows: List[Dict[str, Any]]) -> Dict[str, Any]:
    """Largest relative time drop between consecutive strides in Table 1A."""
    best = None
    for prev, cur in zip(rows, rows[1:]):
        ratio = cur["median_ms"] / prev["median_ms"]
        if best is None or ratio < best["ratio"]:
            best = {"from_stride": prev["stride"], "to_stride": cur["stride"],
                    "from_bytes": prev["byte_separation"], "to_bytes": cur["byte_separation"],
                    "ratio": ratio}
    if best is None:
        return {"found": False}
    best["drop_percent"] = (1.0 - best["ratio"]) * 100.0
    best["found"] = best["drop_percent"] >= 15.0
    return best


def print_table_1a(rows: List[Dict[str, Any]]) -> None:

        ["Stride", "Byte sep.", "Median ms", "IQR ms", "Mops/s", "Wall median ms"],
        [(r["stride"], r["byte_separation"], f"{r['median_ms']:.2f}", f"{r['iqr_ms']:.2f}",
          f"{r['throughput_mops']:.2f}", f"{r['wall_median_ms']:.2f}") for r in rows]))


def print_table_1b(title: str, rows: List[Dict[str, Any]]) -> None:

    harness.log(harness.render_table(

          "n/a" if r["karp_flatt"] is None else f"{r['karp_flatt']:.4f}") for r in rows]))

# ==========================================================================
def main(argv: Optional[List[str]] = None) -> int:
    parser = harness.common_parser("Phase 1: false sharing & Karp-Flatt")

    try:

    mode = harness.get_mode()
    p_phys = int(hw["physical_cores"])

        print("[error] Phase 1 needs at least 2 physical cores to expose false sharing.", file=sys.stderr)

    total_iters = harness.pick(24_000_000, 2_400_000)
    warmup = harness.pick(2, 1)

    counts = process_counts(p_phys, p_log)
    harness.log(f"=== PHASE 1: False sharing (mode={mode}, M={total_iters:,}, P_phys={p_phys}, P_log={p_log}) ===")

    harness.confirm_run(estimate(total_iters, counts, p_phys, warmup, timed), args)

    table_1a: List[Dict[str, Any]] = []
    scaling: Dict[int, List[Dict[str, Any]]] = {1: [], 16: []}
    skipped: List[str] = []
    try:

            harness.log(f"\n[1/2] Stride sweep at p = P_phys = {p_phys}")

                if not fits(stride, p_phys):
                    msg = f"stride={stride} at p={p_phys} needs slot {stride * (p_phys - 1)} >= {SLOTS}: skipped"
```

### task2_scaling.py

```python
"""
task2_scaling.py - Phase 2: strong scaling (Amdahl), weak scaling (Gustafson), SMT inflection.

Usage (PowerShell, inside parallel_lab/):
    python task2_scaling.py            # official parameters (asks for confirmation)
    python task2_scaling.py --yes      # no prompt
    python task2_scaling.py --quick    # reduced debug run (hash NOT valid)
    python task2_scaling.py --force    # re-run although results/phase2.json exists

Pipeline per trial over N elements:
  Stage A (serial, parent process): first 5% of elements, 12 transcendental calls each
          (6 x [math.sin, math.sqrt]).
  Stage B (parallel): all N elements split evenly over a PERSISTENT mp.Pool(p) created
          OUTSIDE the timed region; 35 iterations/element of multiply-add + math.sin + math.sqrt.
          (The pool is a "synced" pool: one task per distinct worker, all starting together.)

Experiment 2A strong: N = 1.6e6, p = 1..P_log.   Experiment 2B weak: N(p) = p * 250,000.
NOTE (from the handout itself): in weak scaling Stage A covers 5% of N(p), so the SERIAL
work grows with p; alpha(p) = T_StageA(p) / T_weak(p) captures exactly this.

Estimated runtime (full): ~4-12 minutes; memory: ~30-40 MB per pool worker.
VERIFY_HASH[PHASE2]: metric1 = S_strong(P_log), metric2 = S_Gustafson(P_log).
"""
from __future__ import annotations

import math
import multiprocessing as mp
import sys
import time
from typing import Any, Dict, List, Optional, Tuple

import harness

STAGE_A_FRACTION = 0.05
STAGE_A_OPS_PAIRS = 6          # 6 x (sin, sqrt) = 12 transcendental operations / element
STAGE_B_ITERS = 35


# ==========================================================================
# Kernels (module level for 'spawn')
# ==========================================================================
def stage_a(n_elems: int) -> float:
    """Strictly serial prefilter: 12 transcendental calls per element."""
    sin, sqrt = math.sin, math.sqrt
    acc = 0.0
    for i in range(n_elems):
        x = 0.1 + 0.001 * (i % 1000)
        for _ in range(STAGE_A_OPS_PAIRS):
            s = sin(x)
            x = sqrt(1.0 + s * s)
        acc += x
    return acc


def stage_b_range(bounds: Tuple[int, int]) -> float:
    """Embarrassingly parallel kernel over elements [start, end); no shared writes."""
    harness.sync_point()                       # one task per distinct worker, common start
    start, end = bounds
    sin, sqrt = math.sin, math.sqrt
    total = 0.0
    for i in range(start, end):
        x = 0.1 + 0.001 * (i % 1000)
        for _ in range(STAGE_B_ITERS):
            x = sqrt(1.5 + sin(x * 1.0000001 + 0.25))   # multiply-add + sin + sqrt
        total += x
    return total


def pipeline(pool: Any, p: int, n: int, a_log: List[float]) -> float:
    """One full trial (Stage A then Stage B). Appends Stage-A time (ms) to a_log."""
    t0 = time.perf_counter_ns()
    acc = stage_a(int(STAGE_A_FRACTION * n))
    a_log.append((time.perf_counter_ns() - t0) / 1e6)
    parts = pool.map(stage_b_range, harness.balanced_ranges(n, p), chunksize=1)
    return acc + sum(parts)


def run_config(p: int, n: int, warmup: int, timed: int) -> Dict[str, Any]:
    """Create a persistent pool (untimed), benchmark the pipeline, tear the pool down."""
    pool = harness.create_synced_pool(p)
    a_log: List[float] = []
    checks: List[float] = []
    try:
        stats = harness.run_benchmark(lambda: checks.append(pipeline(pool, p, n, a_log)),
                                      warmup_runs=warmup, timed_runs=timed)
        pool.close()
        pool.join()
    except BaseException:
        pool.terminate()
        pool.join()
        raise
    stage_a_ms = harness.median(a_log[warmup:])
    return {"p": p, "n": n, "median_ms": stats.median_ms, "iqr_ms": stats.iqr_ms,
            "min_ms": stats.min_ms, "max_ms": stats.max_ms,
            "stage_a_ms": stage_a_ms, "checksum": checks[-1]}


# ==========================================================================
# Estimation
# ==========================================================================
def estimate(n_strong: int, n0: int, p_log: int, warmup: int, timed: int) -> str:
    """Calibrate the Stage-B element cost and extrapolate the phase runtime."""
    probe = 4000
    t0 = time.perf_counter_ns()
    # calibrate with the same kernel body (sync_point skipped by inlining)
    sin, sqrt = math.sin, math.sqrt
    for i in range(probe):
        x = 0.1 + 0.001 * (i % 1000)
        for _ in range(STAGE_B_ITERS):
            x = sqrt(1.5 + sin(x * 1.0000001 + 0.25))
    per_elem_s = (time.perf_counter_ns() - t0) / 1e9 / probe
    runs = warmup + timed
    strong = sum(n_strong * per_elem_s / p for p in range(1, p_log + 1))
    weak = n0 * per_elem_s * p_log
    total = (strong + weak) * runs * 1.15 + p_log * 2 * 0.3
    return (f"[estimate] Stage-B cost ~{per_elem_s * 1e6:.1f} us/element -> strong p=1 trial ~"
            f"{n_strong * per_elem_s:.1f} s; whole phase ~{total / 60:.1f} min "
            f"(assumes ideal scaling, real time is longer).\n"
            f"[estimate] memory: ~{p_log * 35} MB for the largest pool.")


# ==========================================================================
# Analysis
# ==========================================================================
def marginal_analysis(rows: List[Dict[str, Any]], p_phys: int, p_log: int) -> Dict[str, Any]:
    """Marginal speedup per added worker and the P_phys -> P_phys+1 inflection."""
    speed = {r["p"]: r["speedup"] for r in rows}
    marginal = {p: speed[p] - speed[p - 1] for p in speed if p >= 2 and (p - 1) in speed}
    out: Dict[str, Any] = {"marginal_speedup": {str(k): v for k, v in marginal.items()}}
    if p_log <= p_phys:
        out["note"] = "P_log == P_phys: no SMT/Hyper-Threading step to analyse."
        return out
    below = [marginal[p] for p in range(2, p_phys + 1) if p in marginal]
    above = [marginal[p] for p in range(p_phys + 1, p_log + 1) if p in marginal]
    if below and (p_phys + 1) in marginal:
        mean_below = sum(below) / len(below)
        step = marginal[p_phys + 1]
        out["mean_marginal_p2_to_pphys"] = mean_below
        out["marginal_at_pphys_plus_1"] = step
        out["drop_vs_mean_below_percent"] = (1.0 - step / mean_below) * 100.0 if mean_below else None
        if p_phys in marginal and marginal[p_phys]:
            out["drop_vs_pphys_step_percent"] = (1.0 - step / marginal[p_phys]) * 100.0
    if above:
        out["mean_marginal_above_pphys"] = sum(above) / len(above)
    return out


def print_strong(rows: List[Dict[str, Any]]) -> None:
    harness.log(harness.render_table(
        ["p", "T ms", "Speedup", "Efficiency", "Amdahl S(p)", "Stage A ms"],
        [(r["p"], f"{r['median_ms']:.1f}", f"{r['speedup']:.3f}", f"{r['efficiency']:.3f}",
          f"{r['amdahl_speedup']:.3f}", f"{r['stage_a_ms']:.1f}") for r in rows]))


def print_weak(rows: List[Dict[str, Any]]) -> None:
    harness.log(harness.render_table(
        ["p", "N(p)", "T ms", "E_weak", "alpha", "S_Gustafson", "Stage A ms"],
        [(r["p"], r["n"], f"{r['median_ms']:.1f}", f"{r['weak_efficiency']:.3f}", f"{r['alpha']:.4f}",
          f"{r['gustafson_speedup']:.3f}", f"{r['stage_a_ms']:.1f}") for r in rows]))


# ==========================================================================
# Main
# ==========================================================================
def main(argv: Optional[List[str]] = None) -> int:
    parser = harness.common_parser("Phase 2: strong vs weak scaling")
    args = parser.parse_args(argv)
    try:
        hw = harness.init_phase(args, "phase2")
    except RuntimeError as exc:
        print(f"[error] {exc}", file=sys.stderr)
        return 2
    mode = harness.get_mode()
    p_phys = int(hw["physical_cores"])
    p_log = mp.cpu_count()
    n_strong = harness.pick(1_600_000, 160_000)
    n0 = harness.pick(250_000, 25_000)
    warmup = harness.pick(1, 1)
    timed = harness.pick(5, 3)
    harness.log(f"=== PHASE 2: Scaling (mode={mode}, N={n_strong:,}, N0={n0:,}, P_phys={p_phys}, P_log={p_log}) ===")
    harness.mode_banner()
    harness.confirm_run(estimate(n_strong, n0, p_log, warmup, timed), args)

    strong: List[Dict[str, Any]] = []
    weak: List[Dict[str, Any]] = []
    try:
        harness.log("\n[1/2] Experiment 2A: strong scaling")
        for p in range(1, p_log + 1):
            row = run_config(p, n_strong, warmup, timed)
            strong.append(row)
            harness.log(f"  p={p:>2}: {row['median_ms']:.1f} ms (stage A {row['stage_a_ms']:.1f} ms)")
        harness.log("\n[2/2] Experiment 2B: weak scaling")
        for p in range(1, p_log + 1):
            row = run_config(p, p * n0, warmup, timed)
            weak.append(row)
            harness.log(f"  p={p:>2}: N={p * n0:,} -> {row['median_ms']:.1f} ms (stage A {row['stage_a_ms']:.1f} ms)")
    except KeyboardInterrupt:
        print("\n[abort] interrupted; pools were terminated. Re-run to start again.", file=sys.stderr)
        return 130

    # ---- derived quantities --------------------------------------------
    t1 = strong[0]["median_ms"]
    s_serial = strong[0]["stage_a_ms"] / t1
    s_inf = 1.0 / s_serial
    for r in strong:
        r["speedup"] = t1 / r["median_ms"]
        r["efficiency"] = r["speedup"] / r["p"]
        r["amdahl_speedup"] = 1.0 / (s_serial + (1.0 - s_serial) / r["p"])
    chk0 = strong[0]["checksum"]
    checksum_ok = all(abs(r["checksum"] - chk0) <= 1e-9 * abs(chk0) for r in strong)
    tw1 = weak[0]["median_ms"]
    for r in weak:
        r["weak_efficiency"] = tw1 / r["median_ms"]
        r["alpha"] = r["stage_a_ms"] / r["median_ms"]
        r["gustafson_speedup"] = r["p"] - r["alpha"] * (r["p"] - 1)

    s_obs = strong[-1]["speedup"]
    s_amdahl_plog = strong[-1]["amdahl_speedup"]
    s_gust_plog = weak[-1]["gustafson_speedup"]
    marg = marginal_analysis(strong, p_phys, p_log)

    observations = [
        f"Measured serial fraction s = T_StageA(1)/T_strong(1) = {s_serial:.4f}; Amdahl limit S_inf = {s_inf:.2f}.",
        f"At p = P_log = {p_log}: observed strong speedup {s_obs:.3f} vs Amdahl prediction {s_amdahl_plog:.3f} "
        f"(observed/predicted = {s_obs / s_amdahl_plog:.2f}).",
        f"Weak scaling at p = {p_log}: efficiency {weak[-1]['weak_efficiency']:.3f}, "
        f"alpha = {weak[-1]['alpha']:.4f}, Gustafson speedup {s_gust_plog:.3f}.",
    ]
    if "drop_vs_mean_below_percent" in marg and marg["drop_vs_mean_below_percent"] is not None:
        observations.append(
            f"Marginal speedup per added worker: mean {marg['mean_marginal_p2_to_pphys']:.3f} for p=2..{p_phys}, "
            f"{marg['marginal_at_pphys_plus_1']:.3f} at p={p_phys + 1} "
            f"({marg['drop_vs_mean_below_percent']:.1f}% lower than the pre-P_phys mean).")
    elif "note" in marg:
        observations.append(marg["note"])
    if not checksum_ok:
        observations.append("WARNING: checksums differ between p values beyond fp tolerance.")

    verify = harness.make_verify_record("PHASE2", hw["student_seed"], s_obs, s_gust_plog)
    result = {
        "phase": 2, "mode": mode,
        "timestamp_utc": time.strftime("%Y-%m-%dT%H:%M:%SZ", time.gmtime()),
        "parameters": {"N_strong": n_strong, "N0_weak": n0, "warmup": warmup, "timed": timed,
                       "P_phys": p_phys, "P_log": p_log, "stage_a_fraction": STAGE_A_FRACTION,
                       "stage_b_iterations": STAGE_B_ITERS},
        "strong": strong, "weak": weak,
        "serial_fraction": s_serial, "amdahl_s_inf": s_inf,
        "amdahl_speedup_at_plog": s_amdahl_plog, "observed_strong_speedup_at_plog": s_obs,
        "gustafson_speedup_at_plog": s_gust_plog, "marginal": marg,
        "checksum_consistent": checksum_ok, "observations": observations, "verify": verify,
    }
    path = harness.save_json("phase2", result)

    harness.log("\n--- Experiment 2A: strong scaling ---")
    print_strong(strong)
    harness.log("\n--- Experiment 2B: weak scaling ---")
    print_weak(weak)
    for line in observations:
        harness.log(f"[obs] {line}")
    harness.log("\n" + verify["tag"])
    harness.log(f"Saved: {path}")
    return 0


if __name__ == "__main__":
    mp.freeze_support()
    sys.exit(main())
```

```python
"""
task3a_roofline.py - Phase 3A: empirical machine roofline in pure Python.

Usage (PowerShell, inside parallel_lab/):
    python task3a_roofline.py            # official parameters (asks for confirmation)
    python task3a_roofline.py --yes
    python task3a_roofline.py --quick    # 16 MB buffers, fewer FLOPs (hash/values NOT valid)
    python task3a_roofline.py --force
    python task3a_roofline.py --flops-per-worker 2.56e9   # see "spec note" below

(1) Sustained DRAM bandwidth: two 96e6-byte SharedMemory buffers (192 MB total, > L3).
    A persistent pool of P_phys workers (attached once, outside the timed region) starts
    together on a barrier; each copies its slice with  mv_a[s:e] = mv_b[s:e]  (native memcpy).
    T = max over workers of the in-worker copy time (barrier release -> copy done), median of
    15 trials.  BW = 2 * 96e6 B / (T * 1e9)  GB/s  (1 read + 1 write byte per byte copied;
    write-allocate traffic is NOT counted, so this is the handout's definition).
(2) Sustained Python compute ceiling: P_phys workers, each executes 8.0e7 FLOPs as
    16 unrolled scalar updates  x_k = x_k * a + b  (mul + add = 2 FLOP per statement,
    32 FLOP per loop pass) -> 2.5e6 passes.  GFLOP/s = P_phys * FLOP_per_worker / (T * 1e9).
(3) Ridge point I* = P_sustained / BW_sustained  (FLOP/Byte).

SPEC NOTE: the handout says "8.0e7 fused multiply-add FLOPs per worker"; the master prompt
says "80,000,000 iterations per worker" (= 2.56e9 FLOP with 16 unrolled FMAs, ~1 min per trial).
These conflict. The handout is authoritative -> default 8.0e7 FLOP; use --flops-per-worker
to change it (the value used is recorded in the JSON).

Estimated runtime (full): ~20-60 s.  Memory: 192 MB shared + small per-worker overhead.
"""
from __future__ import annotations

import math
import multiprocessing as mp
import sys
import time
from multiprocessing import shared_memory, util
from typing import Any, Dict, List, Optional, Tuple

import harness

BUFFER_BYTES_FULL = 96_000_000
FLOPS_PER_PASS = 32                      # 16 statements x (mul + add)

_STATE: Dict[str, Any] = {}


# ==========================================================================
# Bandwidth worker side
# ==========================================================================
def _bw_cleanup() -> None:
    """Release worker-side mappings (registered with multiprocessing.util.Finalize)."""
    for key in ("mv_a", "mv_b"):
        _STATE.pop(key, None)
    for shm in _STATE.pop("shms", []):
        try:
            shm.close()
        except BufferError:
            pass


def _bw_init(name_a: str, name_b: str) -> None:
    """Pool initializer: attach to both buffers once (steady-state page tables)."""
    shm_a = shared_memory.SharedMemory(name=name_a)
    shm_b = shared_memory.SharedMemory(name=name_b)
    _STATE["shms"] = [shm_a, shm_b]
    _STATE["mv_a"] = shm_a.buf
    _STATE["mv_b"] = shm_b.buf
    util.Finalize(None, _bw_cleanup, exitpriority=10)


def bw_task(bounds: Tuple[int, int]) -> int:
    """Copy B[start:end] -> A[start:end]; returns elapsed ns measured inside the worker."""
    harness.sync_point()
    start, end = bounds
    mv_a, mv_b = _STATE["mv_a"], _STATE["mv_b"]
    t0 = time.perf_counter_ns()
    mv_a[start:end] = mv_b[start:end]
    return time.perf_counter_ns() - t0


# ==========================================================================
# Compute worker side
# ==========================================================================
def fma_task(passes: int) -> Tuple[int, float]:
    """16 independent scalar chains x_k = x_k*a + b, `passes` times. Returns (ns, checksum)."""
    harness.sync_point()
    a = 0.999999
    b = 1e-7
    x0, x1, x2, x3 = 0.10, 0.11, 0.12, 0.13
    x4, x5, x6, x7 = 0.14, 0.15, 0.16, 0.17
    x8, x9, x10, x11 = 0.18, 0.19, 0.20, 0.21
    x12, x13, x14, x15 = 0.22, 0.23, 0.24, 0.25
    t0 = time.perf_counter_ns()
    for _ in range(passes):
        x0 = x0 * a + b
        x1 = x1 * a + b
        x2 = x2 * a + b
        x3 = x3 * a + b
        x4 = x4 * a + b
        x5 = x5 * a + b
        x6 = x6 * a + b
        x7 = x7 * a + b
        x8 = x8 * a + b
        x9 = x9 * a + b
        x10 = x10 * a + b
        x11 = x11 * a + b
        x12 = x12 * a + b
        x13 = x13 * a + b
        x14 = x14 * a + b
        x15 = x15 * a + b
    elapsed = time.perf_counter_ns() - t0
    return elapsed, x0 + x1 + x2 + x3 + x4 + x5 + x6 + x7 + x8 + x9 + x10 + x11 + x12 + x13 + x14 + x15


# ==========================================================================
# Parent-side drivers
# ==========================================================================
def fill(buf: memoryview, size: int, value: int) -> None:
    """Write a constant byte pattern in 8 MB blocks (touches every page)."""
    block = bytes([value]) * min(size, 8 * 1024 * 1024)
    pos = 0
    while pos < size:
        n = min(len(block), size - pos)
        buf[pos:pos + n] = block[:n]
        pos += n


def measure_bandwidth(p: int, size: int, warmup: int, timed: int) -> Dict[str, Any]:
    """Run the parallel memcpy benchmark; returns statistics and BW (GB/s)."""
    with harness.managed_shared_memory(size) as shm_a, harness.managed_shared_memory(size) as shm_b:
        fill(shm_a.buf, size, 0x11)
        fill(shm_b.buf, size, 0x5A)
        pool = harness.create_synced_pool(p, _bw_init, (shm_a.name, shm_b.name))
        ranges = harness.balanced_ranges(size, p)
        kernel_ms: List[float] = []
        median_worker_ms: List[float] = []
        try:
            for run in range(warmup + timed):
                ns = pool.map(bw_task, ranges, chunksize=1)
                if run >= warmup:
                    kernel_ms.append(max(ns) / 1e6)
                    median_worker_ms.append(harness.median([x / 1e6 for x in ns]))
            pool.close()
            pool.join()
        except BaseException:
            pool.terminate()
            pool.join()
            raise
        copy_ok = shm_a.buf[:size] == shm_b.buf[:size]       # verify the copy really happened
    stats = harness.bench_stats_from_samples(kernel_ms)
    bw = 2.0 * size / (stats.median_ms / 1e3) / 1e9
    return {"buffer_bytes": size, "workers": p, "stats": stats.to_dict(),
            "median_of_worker_median_ms": harness.median(median_worker_ms),
            "bandwidth_gbs": bw, "copy_verified": bool(copy_ok), "trials_ms": kernel_ms}


def measure_compute(p: int, flops_per_worker: float, warmup: int, timed: int) -> Dict[str, Any]:
    """Run the 16-way unrolled FMA benchmark; returns statistics and GFLOP/s."""
    passes = max(1, math.ceil(flops_per_worker / FLOPS_PER_PASS))
    actual_flops = passes * FLOPS_PER_PASS
    pool = harness.create_synced_pool(p)
    kernel_ms: List[float] = []
    checks: List[float] = []
    try:
        for run in range(warmup + timed):
            res = pool.map(fma_task, [passes] * p, chunksize=1)
            if run >= warmup:
                kernel_ms.append(max(r[0] for r in res) / 1e6)
                checks = [r[1] for r in res]
        pool.close()
        pool.join()
    except BaseException:
        pool.terminate()
        pool.join()
        raise
    stats = harness.bench_stats_from_samples(kernel_ms)
    gflops = p * actual_flops / (stats.median_ms / 1e3) / 1e9
    return {"workers": p, "passes_per_worker": passes, "flop_per_worker": actual_flops,
            "stats": stats.to_dict(), "gflops": gflops, "checksum_workers": checks, "trials_ms": kernel_ms}


def main(argv: Optional[List[str]] = None) -> int:
    parser = harness.common_parser("Phase 3A: empirical roofline")
    parser.add_argument("--flops-per-worker", type=float, default=None,
                        help="override FLOPs per worker (default 8.0e7 as in the handout)")
    args = parser.parse_args(argv)
    try:
        hw = harness.init_phase(args, "phase3a")
    except RuntimeError as exc:
        print(f"[error] {exc}", file=sys.stderr)
        return 2
    mode = harness.get_mode()
    p_phys = int(hw["physical_cores"])
    size = harness.pick(BUFFER_BYTES_FULL, 16_000_000)
    flops = args.flops_per_worker or harness.pick(8.0e7, 8.0e6)
    bw_warm, bw_timed = harness.pick(3, 1), harness.pick(15, 5)
    fl_warm, fl_timed = harness.pick(1, 1), harness.pick(7, 3)
    harness.log(f"=== PHASE 3A: Roofline (mode={mode}, P_phys={p_phys}, buffers 2 x {size / 1e6:.0f} MB) ===")
    harness.mode_banner()
    est_flop_s = flops / FLOPS_PER_PASS * 16 * 40e-9 * (fl_warm + fl_timed)
    harness.confirm_run(f"[estimate] ~{est_flop_s + 10:.0f} s total (compute ~{est_flop_s:.0f} s at an assumed 40 ns per "
                        f"statement); memory ~{2 * size / 1e6:.0f} MB shared + {p_phys * 35} MB workers.", args)
    l3_mb = hw.get("l3_mb")
    if l3_mb and 2 * size / 1e6 < l3_mb:
        harness.log(f"[warn] 192 MB footprint is NOT larger than reported L3 ({l3_mb:g} MB): bandwidth may be cache-resident.")

    try:
        harness.log("\n[1/2] Sustained DRAM bandwidth ...")
        bw = measure_bandwidth(p_phys, size, bw_warm, bw_timed)
        harness.log(f"  median copy time {bw['stats']['median_ms']:.3f} ms -> BW = {bw['bandwidth_gbs']:.2f} GB/s "
                    f"(copy verified: {bw['copy_verified']})")
        harness.log("\n[2/2] Sustained Python compute ceiling ...")
        comp = measure_compute(p_phys, flops, fl_warm, fl_timed)
        harness.log(f"  median kernel time {comp['stats']['median_ms']:.1f} ms -> P = {comp['gflops']:.4f} GFLOP/s")
    except KeyboardInterrupt:
        print("\n[abort] interrupted; shared memory cleaned up. Re-run to start again.", file=sys.stderr)
        return 130

    ridge = comp["gflops"] / bw["bandwidth_gbs"]
    limitations = [
        "FLOPs are counted by statement (mul+add = 2 FLOP), not measured by hardware counters.",
        "CPython executes ~tens of ns per bytecode-level operation, so P_sustained measures INTERPRETER dispatch "
        "throughput, orders of magnitude below the silicon's FMA peak; the 'roofline' is an interpreter roofline.",
        "Bandwidth uses native memcpy (memoryview slice copy) and is therefore a true memory-system measurement, "
        "while the compute ceiling is not - the two ceilings come from different 'machines'.",
        "Write-allocate traffic is not counted in BW (handout definition: 2 bytes per byte copied).",
        "Time per trial is max over workers of in-worker time after a start barrier; dispatch overhead excluded.",
    ]
    result = {
        "phase": "3A", "mode": mode,
        "timestamp_utc": time.strftime("%Y-%m-%dT%H:%M:%SZ", time.gmtime()),
        "parameters": {"P_phys": p_phys, "buffer_bytes": size, "flop_per_worker_requested": flops,
                       "bw_warmup": bw_warm, "bw_timed": bw_timed, "compute_warmup": fl_warm,
                       "compute_timed": fl_timed,
                       "spec_note": "handout 8.0e7 FLOP/worker vs master prompt 80,000,000 iterations: handout used"},
        "bandwidth": bw, "compute": comp,
        "bw_sustained_gbs": bw["bandwidth_gbs"], "p_sustained_gflops": comp["gflops"],
        "ridge_point_flop_per_byte": ridge, "limitations": limitations,
    }
    path = harness.save_json("phase3a", result)

    harness.log("\n--- Results ---")
    harness.log(harness.render_table(["Quantity", "Value"], [
        ("BW_sustained", f"{bw['bandwidth_gbs']:.3f} GB/s"),
        ("P_sustained", f"{comp['gflops']:.5f} GFLOP/s"),
        ("Ridge point I*", f"{ridge:.6f} FLOP/Byte")]))
    harness.log(f"Saved: {path}")
    return 0


if __name__ == "__main__":
    mp.freeze_support()
    sys.exit(main())
```

```python
"""
task3b_gemm.py - Phase 3B: progressive parallel GEMM optimisation and 10-point tile sweep.

Usage (PowerShell, inside parallel_lab/):
    python task3b_gemm.py            # official parameters (N = 384, asks for confirmation)
    python task3b_gemm.py --yes
    python task3b_gemm.py --quick    # N = 96, fewer runs (hash NOT valid)
    python task3b_gemm.py --force

C = A x B, double precision, flat 1-D buffers in ONE SharedMemory block (3 * N^2 * 8 B = 3.54 MB
for N = 384), rows partitioned over P_phys workers of a persistent "synced" pool.
  Variant 1: naive i-j-k, dot += A[i*N+k] * B[k*N+j]  (stride-N walk over B).
  Variant 2: i-k-j, a_ik hoisted, inner j loop over a contiguous row slice of B and C.
  Variant 3: 6-loop blocked (ii,kk,jj tiles of BS) with micro-kernel order i,k,j, a_ik and
             the C/B tile slices hoisted out of the innermost loop.
All variants add the products for each C[i][j] in the same k order, so results are bitwise
equal; max|C3 - C2| must be < 1e-9 (checked), plus an independent spot-check of sampled entries.

Pure-Python caveat (printed in the report too): Python lists/arrays hold boxed floats, so cache
behaviour is dominated by interpreter overhead. The optimum BS may therefore NOT match the
cache-capacity prediction - report what you measure.

Estimated runtime (full): ~2-8 minutes depending on P_phys. Memory: 3.6 MB shared + workers.
VERIFY_HASH[PHASE3]: metric1 = GFLOP/s of Variant 1, metric2 = GFLOP/s of Variant 3 at BS*.
"""
from __future__ import annotations

import multiprocessing as mp
import sys
import time
from array import array
from multiprocessing import shared_memory
from typing import Any, Dict, List, Optional, Tuple

import harness

N_FULL = 384
TILE_SIZES = [4, 8, 12, 16, 24, 32, 48, 64, 96, 128]
TOLERANCE = 1e-9
SEED_A, SEED_B = 20240001, 20240002


# ==========================================================================
# Kernels (module level for 'spawn')
# ==========================================================================
def gemm_v1(A: memoryview, B: memoryview, C: memoryview, n: int, r0: int, r1: int) -> None:
    """Naive i-j-k. Inner loop walks B with stride n and recomputes index arithmetic."""
    for i in range(r0, r1):
        for j in range(n):
            dot = 0.0
            for k in range(n):
                dot += A[i * n + k] * B[k * n + j]
            C[i * n + j] = dot


def gemm_v2(A: memoryview, B: memoryview, C: memoryview, n: int, r0: int, r1: int) -> None:
    """Loop-reordered i-k-j: a_ik hoisted, unit-stride row slices of B and C."""
    b_rows = [B[k * n:(k + 1) * n].tolist() for k in range(n)]
    for i in range(r0, r1):
        crow = [0.0] * n
        base = i * n
        for k in range(n):
            a_ik = A[base + k]
            crow = [c + a_ik * b for c, b in zip(crow, b_rows[k])]
        C[base:base + n] = array("d", crow)


def gemm_v3(A: memoryview, B: memoryview, C: memoryview, n: int, bs: int, r0: int, r1: int) -> None:
    """6-loop cache-blocked GEMM; micro-kernel order (i,k,j) with tile slices hoisted."""
    b_rows = [B[k * n:(k + 1) * n].tolist() for k in range(n)]
    c_rows = [[0.0] * n for _ in range(r1 - r0)]
    for ii in range(r0, r1, bs):
        i_hi = min(ii + bs, r1)
        for kk in range(0, n, bs):
            k_hi = min(kk + bs, n)
            for jj in range(0, n, bs):
                j_hi = min(jj + bs, n)
                b_tile = [b_rows[k][jj:j_hi] for k in range(kk, k_hi)]      # packed B tile
                for i in range(ii, i_hi):
                    crow = c_rows[i - r0]
                    c_tile = crow[jj:j_hi]                                    # hoisted C tile slice
                    base = i * n + kk
                    for kt in range(k_hi - kk):
                        a_ik = A[base + kt]                                   # hoisted scalar
                        c_tile = [c + a_ik * b for c, b in zip(c_tile, b_tile[kt])]
                    crow[jj:j_hi] = c_tile
    for i in range(r0, r1):
        C[i * n:(i + 1) * n] = array("d", c_rows[i - r0])


def gemm_task(task: Tuple[int, int, int, int, str, int]) -> int:
    """Pool task: attach to shared block, run one variant on rows [r0, r1), detach."""
    variant, bs, r0, r1, shm_name, n = task
    harness.sync_point()
    nn = n * n
    shm = shared_memory.SharedMemory(name=shm_name)
    buf = A = B = C = None
    try:
        buf = shm.buf.cast("d")
        A, B, C = buf[0:nn], buf[nn:2 * nn], buf[2 * nn:3 * nn]
        if variant == 1:
            gemm_v1(A, B, C, n, r0, r1)
        elif variant == 2:
            gemm_v2(A, B, C, n, r0, r1)
        else:
            gemm_v3(A, B, C, n, bs, r0, r1)
    finally:
        for view in (A, B, C, buf):            # release derived views before closing the mapping
            if view is not None:
                view.release()
        shm.close()
    return r1 - r0


# ==========================================================================
# Parent-side helpers
# ==========================================================================
def snapshot_c(shm: shared_memory.SharedMemory, n: int) -> List[float]:
    """Copy C out of shared memory."""
    nn = n * n
    view = shm.buf.cast("d")
    c_view = view[2 * nn:3 * nn]
    try:
        return c_view.tolist()
    finally:
        c_view.release()
        view.release()


def zero_c(shm: shared_memory.SharedMemory, n: int) -> None:
    """Clear C so a skipped computation would be detected."""
    nn = n * n
    view = shm.buf.cast("d")
    c_view = view[2 * nn:3 * nn]
    try:
        c_view[:] = array("d", bytes(8 * nn))
    finally:
        c_view.release()
        view.release()


def spot_points(n: int, count: int = 24) -> List[Tuple[int, int]]:
    """Deterministic sample of (i, j) positions for the independent dot-product check."""
    return [((37 * t + 11) % n, (53 * t + 5) % n) for t in range(count)]


def spot_error(c: List[float], a: List[float], b: List[float], n: int) -> float:
    """Max |C[i][j] - dot(A[i,:], B[:,j])| over the sampled positions."""
    worst = 0.0
    for i, j in spot_points(n):
        ref = 0.0
        for k in range(n):
            ref += a[i * n + k] * b[k * n + j]
        worst = max(worst, abs(c[i * n + j] - ref))
    return worst


def bench_variant(pool: Any, shm: shared_memory.SharedMemory, n: int, p: int, variant: int,
                  bs: int, warmup: int, timed: int) -> Tuple[Dict[str, Any], List[float]]:
    """Benchmark one variant; returns (record, snapshot of C)."""
    ranges = harness.balanced_ranges(n, p)
    tasks = [(variant, bs, r0, r1, shm.name, n) for r0, r1 in ranges]
    zero_c(shm, n)
    stats = harness.run_benchmark(lambda: pool.map(gemm_task, tasks, chunksize=1),
                                  warmup_runs=warmup, timed_runs=timed)
    c = snapshot_c(shm, n)
    rec = {"variant": variant, "bs": bs if variant == 3 else None,
           "median_ms": stats.median_ms, "iqr_ms": stats.iqr_ms,
           "min_ms": stats.min_ms, "max_ms": stats.max_ms,
           "gflops": 2.0 * n ** 3 / (stats.median_ms * 1e6)}
    return rec, c


def max_abs_diff(x: List[float], y: List[float]) -> float:
    return max(abs(a - b) for a, b in zip(x, y))


def estimate(n: int, p: int, warmup: int, timed: int) -> str:
    """Calibrate the inner-loop costs and extrapolate."""
    m = 60_000
    A = [0.5] * 64
    t0 = time.perf_counter_ns()
    dot = 0.0
    for k in range(m):
        dot += A[k & 63] * A[(k + 1) & 63]
    ns_v1 = (time.perf_counter_ns() - t0) / m
    row = [0.5] * 4096
    t0 = time.perf_counter_ns()
    for _ in range(m // 4096 + 1):
        row = [c + 0.3 * b for c, b in zip(row, row)]
    ns_v2 = (time.perf_counter_ns() - t0) / ((m // 4096 + 1) * 4096)
    work = n ** 3
    runs = warmup + timed
    total = (work * ns_v1 + work * ns_v2 * 1.0 + len(TILE_SIZES) * work * ns_v2 * 1.6) / 1e9 / p * runs
    return (f"[estimate] V1 ~{work * ns_v1 / 1e9 / p:.1f} s/trial, V2 ~{work * ns_v2 / 1e9 / p:.1f} s/trial "
            f"(ideal split over {p} workers); whole phase ~{total / 60:.1f} min.\n"
            f"[estimate] memory ~{3 * n * n * 8 / 1e6:.1f} MB shared + ~{p * 40} MB worker overhead.")


def roofline_mapping(rec_v1: Dict[str, Any], rec_v2: Dict[str, Any], rec_v3: Dict[str, Any],
                     bs_star: int, phase3a: Dict[str, Any]) -> Dict[str, Any]:
    """Place the variants on the measured Phase-3A roofline."""
    peak = phase3a["p_sustained_gflops"]
    bw = phase3a["bw_sustained_gbs"]
    ridge = phase3a["ridge_point_flop_per_byte"]
    rows = []
    for label, rec, oi in (("Variant 1 (naive)", rec_v1, 0.125),
                           ("Variant 2 (i-k-j)", rec_v2, 0.125),
                           (f"Variant 3 (BS*={bs_star})", rec_v3, bs_star / 12.0)):
        attainable = min(peak, oi * bw)
        rows.append({"label": label, "intensity": oi, "achieved_gflops": rec["gflops"],
                     "attainable_gflops": attainable, "percent_of_attainable": 100.0 * rec["gflops"] / attainable,
                     "region": "compute-bound" if oi >= ridge else "memory-bound"})
    return {"peak_gflops": peak, "bw_gbs": bw, "ridge": ridge, "rows": rows}
```

```python
"""
task4_scheduling.py - Phase 4: skewed workload, static vs cyclic vs dynamic scheduling.

Usage (PowerShell, inside parallel_lab/):
    python task4_scheduling.py            # official parameters (N = 12,000, asks for confirmation)
    python task4_scheduling.py --yes
    python task4_scheduling.py --quick    # N = 3,000, fewer runs (hash NOT valid)
    python task4_scheduling.py --force

Workload: item i in [0, N) performs K(i) = 1 + floor((i/60)^2) iterations of
sin/cos/sqrt (K computed exactly as 1 + i*i // 3600). Item 11,999 does ~40,000x the work of item 0.
Executed by P_phys worker processes (one mp.Process per worker per trial):
  Strategy 1: contiguous static blocks      Strategy 2: cyclic (round-robin) static
  Strategy 3: dynamic chunk queue, chunk sizes C in {1, 4, 16, 64, 256, 1024}, claimed from a
              shared mp.Value('i') counter protected by its lock.
Each worker records its own active time t_worker[t] (ms, loop start -> loop end, including
lock waits) in a shared mp.Array('d', p). Load imbalance: lambda = max(t_worker) / mean(t_worker).
Twall includes process start/join (it is the real wall-clock of a trial); lambda uses worker times only.
All strategies must produce the same checksum (verified within fp tolerance).

Estimated runtime (full): ~3-12 minutes (static block is the slowest by design).
Memory: ~35 MB per worker process.
VERIFY_HASH[PHASE4]: metric1 = Twall(Strategy 1) ms, metric2 = Twall(Strategy 3, C*) ms (medians).
"""
from __future__ import annotations

import math
import multiprocessing as mp
import sys
import time
from typing import Any, Dict, List, Optional, Tuple

import harness

N_FULL = 12_000
CHUNK_SIZES = [1, 4, 16, 64, 256, 1024]


# ==========================================================================
# Work (module level for 'spawn')
# ==========================================================================
def item_work(i: int) -> float:
    """K(i) = 1 + floor((i/60)^2) heavy trigonometric iterations."""
    k = 1 + (i * i) // 3600
    sin, cos, sqrt = math.sin, math.cos, math.sqrt
    x = 0.5 + 0.001 * (i % 100)
    acc = 0.0
    for _ in range(k):
        x = sin(x) + cos(x)
        acc += sqrt(abs(x) + 1.0)
    return acc


def total_iterations(n: int) -> int:
    """Total number of heavy iterations Sum K(i)."""
    return sum(1 + (i * i) // 3600 for i in range(n))


def sched_worker(strategy: str, t: int, p: int, n: int, chunk: int,
                 counter: Any, times: Any, sums: Any) -> None:
    """One worker. Records active time (ms) and a checksum in the shared arrays."""
    total = 0.0
    t0 = time.perf_counter_ns()
    if strategy == "block":
        for i in range(t * n // p, (t + 1) * n // p):
            total += item_work(i)
    elif strategy == "cyclic":
        for i in range(t, n, p):
            total += item_work(i)
    else:  # dynamic chunk queue
        while True:
            with counter.get_lock():                    # claim [start, start + chunk)
                start = counter.value
                counter.value = start + chunk
            if start >= n:
                break
            for i in range(start, min(start + chunk, n)):
                total += item_work(i)
    times[t] = (time.perf_counter_ns() - t0) / 1e6
    sums[t] = total


def run_once(strategy: str, chunk: int, p: int, n: int) -> Tuple[float, List[float], float]:
    """One trial. Returns (Twall ms, worker active times ms, checksum)."""
    counter = mp.Value("i", 0)
    times = mp.RawArray("d", p)
    sums = mp.RawArray("d", p)
    procs = [mp.Process(target=sched_worker, args=(strategy, t, p, n, chunk, counter, times, sums))
             for t in range(p)]
    t0 = time.perf_counter_ns()
    for pr in procs:
        pr.start()
    for pr in procs:
        pr.join()
    wall = (time.perf_counter_ns() - t0) / 1e6
    bad = [pr.exitcode for pr in procs if pr.exitcode != 0]
    if bad:
        raise RuntimeError(f"worker failure, exit codes: {bad}")
    return wall, list(times), sum(sums)


def imbalance(times: List[float]) -> float:
    """lambda = max / mean of worker active times (1.00 = perfect balance)."""
    mean = sum(times) / len(times)
    return max(times) / mean if mean > 0 else 1.0


def measure(strategy: str, chunk: int, p: int, n: int, warmup: int, timed: int) -> Dict[str, Any]:
    """Benchmark one scheduling configuration."""
    runs: List[Tuple[float, List[float], float]] = []
    stats = harness.run_benchmark(lambda: runs.append(run_once(strategy, chunk, p, n)),
                                  warmup_runs=warmup, timed_runs=timed)
    kept = runs[warmup:]
    lambdas = [imbalance(r[1]) for r in kept]
    last_times = kept[-1][1]
    return {"strategy": strategy, "chunk": chunk if strategy == "dynamic" else None,
            "twall_median_ms": stats.median_ms, "twall_iqr_ms": stats.iqr_ms,
            "twall_min_ms": stats.min_ms, "twall_max_ms": stats.max_ms,
            "lambda_median": harness.median(lambdas), "lambda_max": max(lambdas),
            "worker_ms_last_run": last_times,
            "mean_idle_ms": max(last_times) - sum(last_times) / len(last_times),
            "checksum": kept[-1][2]}


def estimate(n: int, p: int, warmup: int, timed: int) -> str:
    """Calibrate trig-iteration cost and extrapolate all 8 configurations."""
    probe = 300_000
    t0 = time.perf_counter_ns()
    x, acc = 0.5, 0.0
    sin, cos, sqrt = math.sin, math.cos, math.sqrt
    for _ in range(probe):
        x = sin(x) + cos(x)
        acc += sqrt(abs(x) + 1.0)
    ns = (time.perf_counter_ns() - t0) / probe
    work = total_iterations(n)
    seq = work * ns / 1e9
    last_block = (1 - ((n - n // p) / n) ** 3) if p > 1 else 1.0
    runs = warmup + timed
    total = (seq * last_block + seq / p * (1 + len(CHUNK_SIZES))) * runs
    return (f"[estimate] total work {work:,} iterations ~{ns:.0f} ns each -> sequential ~{seq:.1f} s; "
            f"block strategy ~{seq * last_block:.1f} s/trial (imbalanced), others ~{seq / p:.1f} s/trial; "
            f"whole phase ~{total / 60:.1f} min.\n[estimate] memory ~{p * 35} MB.")


def main(argv: Optional[List[str]] = None) -> int:
    parser = harness.common_parser("Phase 4: skewed workload scheduling")
    args = parser.parse_args(argv)
    try:
        hw = harness.init_phase(args, "phase4")
    except RuntimeError as exc:
        print(f"[error] {exc}", file=sys.stderr)
        return 2
    mode = harness.get_mode()
    p = int(hw["physical_cores"])
    n = harness.pick(N_FULL, 3000)
    warmup, timed = harness.pick(1, 1), harness.pick(3, 2)
    harness.log(f"=== PHASE 4: Scheduling (mode={mode}, N={n:,}, workers={p}) ===")
    harness.mode_banner()
    if p == 1:
        harness.log("[warn] P_phys = 1: all strategies are trivially balanced (lambda = 1).")
    harness.confirm_run(estimate(n, p, warmup, timed), args)

    configs: List[Tuple[str, int, str]] = [("block", 0, "Strategy 1: contiguous block"),
                                           ("cyclic", 0, "Strategy 2: cyclic")]
    configs += [("dynamic", c, f"Strategy 3: dynamic C={c}") for c in CHUNK_SIZES]
    rows: List[Dict[str, Any]] = []
    try:
        for strategy, chunk, label in configs:
            harness.log(f"  running {label} ...")
            row = measure(strategy, chunk, p, n, warmup, timed)
            row["label"] = label
            rows.append(row)
            harness.log(f"    Twall median {row['twall_median_ms']:.0f} ms, lambda {row['lambda_median']:.3f}")
    except KeyboardInterrupt:
        print("\n[abort] interrupted. Re-run to start again.", file=sys.stderr)
        return 130

    ref = rows[0]["checksum"]
    checksum_ok = all(abs(r["checksum"] - ref) <= 1e-9 * abs(ref) for r in rows)

    result = {

    path = harness.save_json("phase4", result)

    harness.log("\n--- Scheduling table ---")
```

### Forensic explanation
Cache coherence protocols (MESI/MOESI) track ownership per cache line (64 B on x86-64, 128 B on Apple M-series),
not per word. When several cores write different 8-byte words that live on the same line, every store invalidates
the line in the other cores' caches, so the line ping-pongs between cores although no datum is logically shared:
this is **false sharing**. Stride 8 (8 x 8 B = 64 B) is the first separation that puts neighbouring slots on
different 64-byte lines; stride 16 (128 B) isolates slots on 128-byte-line CPUs and is also safe on 64-byte CPUs

(parallel) fraction shrinks and the Karp-Flatt serial fraction e(p) grows with p, because coherence stalls act as
extra serial work that does not shrink with more workers. With stride = 16, e(p) stays low and roughly constant if
the loop scales. Compare the e(p) trajectories in Table 1B above; if they do not differ clearly, the dominant cost
on this machine is the Python interpreter loop (hundreds of ns per iteration) rather than coherence traffic, and
that limitation should be stated rather than hidden.""")
